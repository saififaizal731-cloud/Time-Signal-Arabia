FOUR MAIN TABS YOU CAN ACCESS
═══════════════════════════════════════════════════════════════════════════════

1. 🌐 CONNECTION
   - Internet Connection Type (DHCP / Static IP / PPPoE)
   - IP Address (if Static)
   - Subnet Mask (if Static)
   - Default Gateway (if Static)
   - Primary DNS Server
   - Secondary DNS Server
   - DHCP Server Enable/Disable
   - DHCP Pool Range

2. 📡 WI-FI SETTINGS
   - 2.4GHz SSID (Network Name)
   - 2.4GHz Security Protocol (WPA2/WPA3)
   - 2.4GHz Password
   - 5GHz SSID (Network Name)
   - 5GHz Security Protocol (WPA2/WPA3)
   - 5GHz Password
   - Guest Network Enable/Disable
   - Guest SSID
   - Guest Password
   - Guest Network Isolation

3. 🔐 SECURITY & FIREWALL
   - Port Forwarding Rules (Add/Remove)
     * Internal Port
     * External Port
     * Protocol (TCP/UDP/Both)
     * Target IP
   - VPN Client Configuration
     * VPN Enable/Disable
     * VPN Type (OpenVPN/WireGuard)
     * VPN Server Address
     * VPN Port
     * VPN Username
     * VPN Password

4. ⚙️ SYSTEM ADMIN
   - Change Admin Password
     * Current Password
     * New Password
     * Confirm Password
   - Firmware Update
     * Current Version
     * Check for Updates button
     * Update Progress Bar
   - Backup Configuration
     * Download Backup button
   - Restore Configuration
     * Upload/Choose File button
   - Factory Reset (warning popup)

STILL CAN'T FIND IT?
═══════════════════════════════════════════════════════════════════════════════

Try these troubleshooting steps:

1. Reload the page: Press Ctrl+R (or Cmd+R on Mac)
2. Clear cache: Press Ctrl+Shift+Delete
3. Close browser and reopen it
4. Make sure npm start is running (check terminal)
5. Try a different browser
6. Open Developer Console: Press F12
   - Look for any red error messages
   - Check if openSettings function exists
   - Check the HTML has the Settings button

If still stuck:
- Check your internet connection
- Make sure you're on http://localhost:5000 (not HTTPS)
- Restart the npm server
